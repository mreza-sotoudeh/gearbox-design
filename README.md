# Gearbox Design

  <img src="gearbox-assembly.png" alt="Cutaway view of the gearbox assembly" width="720">
</p>

Mechanical design and analysis of a two-stage reduction gearbox, developed as an academic machine-design project.

The project covers the complete design process from power transmission requirements and gear calculations to shaft design, bearing selection, housing design, and the final SolidWorks assembly.

## Project Overview

The gearbox receives power from an 11 kW motor through a V-belt drive. Speed reduction is achieved using a helical gear stage followed by a bevel gear stage.

| Parameter            |              Value |
| -------------------- | -----------------: |
| Motor power          |              11 kW |
| Motor speed          |           1440 rpm |
| Gearbox input speed  |            500 rpm |
| Helical-stage ratio  |               2.95 |
| Bevel-stage ratio    |               2.45 |
| Total internal ratio | Approximately 7.23 |

## Design Scope

* Helical and bevel gear design
* Shaft design and strength calculations
* Bearing selection and arrangement
* Gearbox housing and cover design
* Fastener, seal, and retaining-element selection
* Complete 3D assembly and engineering drawings
